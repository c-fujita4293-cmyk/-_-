FIT LOG — HTML/CSS/JavaScript Web App

使い方
1. ZIPを展開します。
2. index.html をChromeやSafariで開きます。
3. 「トレーニングを記録」から種目などを入力し、「記録を保存」を押します。
4. 履歴タブで日付を選び、記録を確認・編集・削除できます。
5. 右上の矢印ボタンからJSONバックアップを書き出し、または読み込めます。

データ保存について
- 記録はブラウザーの localStorage に保存され、同じブラウザー・同じ保存元で再度開いた際に残ります。
- サーバーには送信されず、別の端末とは同期しません。
- ブラウザーのデータ消去やプライベートブラウズの終了で失われる場合があるため、定期的にJSONバックアップを書き出してください。
- file:// で直接開いた場合、ブラウザーによって保存の挙動が異なることがあります。安定利用には、フォルダをローカルWebサーバーで開くか、静的ホスティングに公開してください。

料金ルール
- 月会費比較額: 3,278円
- 都度利用: 1,650円/回
- 月間差額: 1,650円×月間利用日数 − 3,278円
- 月間実質料金: 3,278円 ÷ 月間利用日数（0回は「—」）
- 年間換算額: 3,278円×12 = 39,336円
- 年間差額: 1,650円×年間利用日数 − 39,336円
- 利用回数はトレーニング記録の件数ではなく、利用した日付の重複を除いた日数として集計します。
- 年間集計は、ホームで選択している年の1〜12月に保存された記録を対象とします。

注意
- これは個人用のブラウザー内保存Webアプリです。ログイン、クラウド同期、LifeFit公式システム連携はありません。
- デザインや計算の改善は可能ですが、実際の料金プラン・請求条件は契約内容を確認してください。
